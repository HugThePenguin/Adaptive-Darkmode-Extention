# Security reports

For a security issue or a report containing sensitive details, contact **penguin.x.product@gmail.com** rather than posting a public issue. Include the extension version, impact and the minimum steps needed to reproduce it. Do not send passwords, session tokens or full browser profiles.

This is a volunteer-maintained project. No fixed response time or bug bounty is promised. Ordinary appearance problems and suggestions belong in the feedback forms linked from the README.

セキュリティ上の問題は公開Issueに詳細を書かず、上記メールアドレスへご連絡ください。
