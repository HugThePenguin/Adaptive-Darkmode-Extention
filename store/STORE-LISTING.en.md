## Name

Adaptive Dark

## Short description

Darken bright websites, adjust contrast and color temperature, and keep native dark themes when detected.

## Detailed description — copy the text below

Give bright websites a darker appearance that suits you.

Adaptive Dark adjusts backgrounds and text without inverting the entire page. Choose a warm sepia tone, a neutral gray, or a cooler look, and save your preferences for each website.

Features
• Adjustable background brightness and a continuous warm-to-cool color temperature slider.
• Text contrast targets of 4.5:1 or 7:1 on supported CSS backgrounds.
• Auto mode that leaves a website's own dark colors unchanged when a native dark theme is detected.
• ON and OFF controls for each website, plus a global switch.
• An options page with defaults for all websites and tabs for saved website settings.
• Website overrides apply only to the settings you change; other settings follow your defaults. Reset one website or delete all website overrides.
• Dark loading backgrounds help reduce white flashes while pages and new content are being prepared.
• The entire options page previews your background brightness, color temperature and text contrast.
• Regular images and videos keep their original colors.
• Settings panel colors follow your chosen temperature. When using a website's original background, the panel uses a slightly brighter shade.
• Unused adjustments are disabled while the extension is OFF or using a detected native dark theme.
• An optional control to hide CSS background images when stubborn white backgrounds remain.

How to use
1. Open a website and click the Adaptive Dark icon.
2. Start with Auto. Choose ON to apply adjustments regardless of detection, or OFF to keep the website unchanged.
3. Adjust brightness, temperature, and text contrast. Preferences are saved for that website's hostname.
4. Choose “Edit defaults” to open the options page. The Settings tab sets defaults for all websites; website tabs edit individual overrides. Changes are saved automatically.

Privacy
Appearance processing happens locally in your browser. Global and site preferences, including configured hostnames, are stored locally. The extension does not automatically send your browsing data to the publisher and has no extension accounts, analytics, or ads. It may load a background image already referenced by the website to inspect its dimensions. The Support page lets you review and copy diagnostic information and voluntarily submit feedback through English/Japanese Google Forms. Optional submitted reports are used privately for troubleshooting, requests and replies. See the privacy policy for details.

Adaptive Dark is open source under the MIT license. Find the source code and contribution guide on GitHub: https://github.com/HugThePenguin/Adaptive-Darkmode-Extention

Things to know
Dark mode detection may not always be accurate; ON and OFF let you choose manually. Some special layouts may need adjustment. Contrast targets apply to supported CSS backgrounds, not to text inside images, videos, or every possible layered background. Optional CSS image hiding can also hide background photos. Browser-internal pages, the Chrome Web Store, and other protected pages cannot be modified. English and Japanese interfaces follow your browser's language.
